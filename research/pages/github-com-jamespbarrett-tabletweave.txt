# Tablet Weaving Draft Designer

[Permalink: Tablet Weaving Draft Designer](https://github.com/jamespbarrett/tabletweave#tablet-weaving-draft-designer)

This is a simple javascript based application intended to help practictioners of the ancient art of tablet weaving who
wish to design their own drafts.

The live version of this can be found at:

[http://bazzalisk.org/tabletweave/](http://bazzalisk.org/tabletweave/)

## About

A tool for designing tablet weaving drafts
